# Screenshots

The seven screenshots the book asks for (`[SCREENSHOT NEEDED]` placeholders), kept apart from the chapter text. Each is 1280 px wide at 2x (2560 px), captured with headless Chromium from the chapter's own companion folder running against Postgres, Bogie v0.6.8. The welcome shot was taken on Go 1.26.0.

The files used to be named for the old chapter numbers (6, 7, 9, 11, 14, 16, 17). They now use the new numbers.

| File | Chapter | What it shows |
| --- | --- | --- |
| `ch01-welcome.png` | 1 | The welcome page of a fresh app at http://localhost:8080 |
| `ch03-catalog.png` | 3 | The catalog after seeding: seven products |
| `ch06-add-to-cart.png` | 6 | A product page after adding the mug twice: "Cart (2)" |
| `ch08-sale.png` | 8 | The cart with one mug and the launch weekend 20% off |
| `ch11-admin.png` | 11 | The admin products page, signed in as staff |
| `ch13-categories.png` | 13 | The catalog filtered to Stickers: category menu with counts, page numbers below |
| `ch14-mailpit.png` | 14 | Mailpit with the order confirmation open |

Notes: the product pictures are the project's placeholder images. For Chapter 13 the Stickers category was filled with 12 extra sticker products (14 in all) so a second page exists, since the seed data has only seven products.
