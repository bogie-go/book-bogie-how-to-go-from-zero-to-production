# Chapter 20: When to Break the Conventions

Chapter 20 has no code. It looks back at the problems Chapter 18 met without a framework, describes the signs that a convention no longer fits and how to step outside Bogie without fighting it, and lists common next steps for a growing shop (payments, variants, rate limiting, keyset paging, a managed database, metrics and tracing, using the contract). This folder is a README only.

The finished app is in [Chapter 17](../ch17-keep-the-shop-healthy/): Bogie Depot as it stands at the end of the book's code. Bogie version: v0.6.8.
