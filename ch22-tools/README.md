# Chapter 22: The Tools Bogie Brings

Chapter 22 has no code. It introduces each tool in a Bogie app on its own (Gin, pgx, sqlc, goose, Ginkgo and Gomega, River, golangci-lint, Docker and Kamal, the Postgres shell tools) and Bogie's own commands. This folder is a README only.

The finished app is in [Chapter 20](../ch20-healthy/): Bogie Depot as it stands at the end of the book's code. Bogie version: v0.6.8.

To try the commands the chapter names, run them in that folder: `bogie doctor`, `bogie routes`, `bogie lint`, `bogie d` (to undo a generator), `bogie app:update --pretend`, and `bogie credentials:show`, `credentials:get` or `credentials:edit` (the last three need your own credentials, which this repo does not commit).
