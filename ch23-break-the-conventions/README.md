# Chapter 23: When to Break the Conventions

Chapter 23 has no code. It looks back at the problems Chapter 5 met without a framework, describes the signs that a convention no longer fits and how to step outside Bogie without fighting it, and lists common next steps for a growing shop (payments, variants, rate limiting, keyset paging, a managed database, metrics and tracing, using the contract). This folder is a README only.

The finished app is in [Chapter 20](../ch20-healthy/): Bogie Depot as it stands at the end of the book's code. Bogie version: v0.6.8.
